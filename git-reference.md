
# Git Command Reference

A collection of useful Git commands for managing my projects.

## Basic Commands

Check the current repository status:

```bash
git status
```

View commit history:

```bash
git log --oneline
```

Add a specific file:

```bash
git add filename
```

Add all changes:

```bash
git add .
```

Save changes with a commit:

```bash
git commit -m "Describe your changes"
```

Upload commits to GitHub:

```bash
git push origin main
```

Download the latest changes:

```bash
git pull origin main
```

Clone a repository:

```bash
git clone repository-url
```

## Why Git Is Important

Git helps developers track changes, recover previous versions, organize their work, and collaborate with other developers.
